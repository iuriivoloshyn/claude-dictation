# claude-dictation: notes for agents

This repo installs "hold F5 to dictate anywhere" on a user's Mac. If the user asked you to install, update, check,
fix or remove it, follow README.md. It is written for you: preflight, `./install.sh`, the permissions only the user
can click, then `./verify.sh`.

Never read, copy or move Claude Code credentials. The tool only drives the unmodified `claude` CLI in tmux.
